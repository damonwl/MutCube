# MutCube 完整交互原型

> 2026-09-17：此目录保留此前界面评审材料。旧健身原型不再对应 App 实现，也不是兼容入口；当前通用模板协议见 ../../docs/TEMPLATE_MODULES.md。

入口：`index.html`  
当前实现：`prototype-v2.html`

健身模板独立原型：[`fitness.html`](fitness.html)。保留原 App 原型不变。

健身原型包含基本信息、首份计划生成/确认、按组录入与自动保存草稿、提交后下一次计划预览、训练日历、基本信息编辑和同项目计划讨论的模拟页面。输入与演示记录存储在浏览器本地独立命名空间，不调用 AI、不操作 App 数据库。右上角菜单可让下一次提交后的计划生成模拟失败，重试不会重复保存记录。顶部“重置演示”只清除这个健身原型的数据。

该原型的计划和聊天回复为固定示例，分化等信息不会实际驱动计划计算。浏览器自动打开本地文件被安全策略阻止；本轮仅通过内联脚本语法与差异检查，尚未完成点击、视觉和响应式验收。请手动打开后评审。

## 使用方式

打开原型后，可直接操作主界面；页面下方的“功能地图”用于快速访问全部功能页。原型中的保存、删除、备份、通知和外部跳转只显示交互反馈，不修改真实数据。

## 页面覆盖

### 聊天与组织

- 空白首页、输入框展开、附件、模型强度；
- 已有回答、流式生成、失败与重试；
- 消息复制、分享、重新生成、朗读和更多操作；
- 对话设置、统计、导出、桌面快捷方式和删除；
- 所有聊天、搜索、置顶、最近、收藏和回收站；
- 项目查看、新建、模型覆盖、项目记忆和项目模板；
- 独立翻译页面。

### 模型与扩展

- Provider 列表、详情、新建、启停、导入、导出和连接诊断；
- 模型目录、收藏、别名、图标和能力声明；
- MCP 服务、新建连接、OAuth、工具启停和权限策略；
- 快捷提示词、Skills、对话模式和知识条目；
- 全局与项目记忆管理。

### 设置与数据

- 设置搜索和各入口的状态摘要；
- 主题、字号、聊天气泡、背景和启动行为；
- TTS、ASR、自动朗读及独立语音服务；
- 后台生成、通知和振动反馈；
- Token 统计、请求日志和生成详情；
- 本地备份、WebDAV、S3、文件存储和缓存；
- 开发者选项、安全诊断、版本更新和开源许可。

### 模板

- 模板首页、搜索和同层返回聊天；
- 渐进训练和深度学习两个不同业务形态的详情页；
- 模板结构化数据、运行日志和隐式 AI 任务的界面占位。

## 验证边界

系统分享面板、相机、系统文件选择器、通知权限、OAuth 浏览器和桌面快捷方式属于 Android 系统界面，在 HTML 原型中以明确的结果提示表示，不仿造系统页面。
