# MutCube v0.1.3 · 首个 GitHub 预发布版本

MutCube 是开源 Android AI 客户端与模板服务平台。本次为开发阶段预发布，采用 MIT 许可证；名称与 Logo 的商标使用权不随软件许可证自动授予。

## 主要功能

- 多 Provider 与模型管理，支持 OpenAI-compatible、Google 和 Anthropic 协议。
- 项目与聊天、消息分支、Markdown、图片与文档附件、收藏、搜索及生成统计。
- Agent Skills、MCP 工具、项目记忆与上下文管理。
- TTS/ASR 服务配置、朗读停止、音色选择和录音波形。
- 内置健身模板：资料整理、AI 候选计划、实际训练记录和日历；计划经用户启用才生效。
- 第三方模板包导入、项目授权、声明式数据/AI Action、浏览器 SDK 与 Mock Host；英语学习模板为官方开发样板。
- 本地、WebDAV 与 S3 备份恢复；API Key 等凭据不进入备份。

## 下载与安装

- 下载 Release 附件 `MutCube-0.1.3-release.apk`，支持 Android 8.0（API 26）及以上。
- 正式包名为 `com.dwl.mutcube`，版本号 `0.1.3`，`versionCode=4`。
- 与本机此前分发的 0.1.2 使用同一发布证书，可覆盖升级；升级前建议备份数据。
- Debug/Alpha 包使用独立包名，数据不会自动迁移到正式版。
- `SHA256SUMS.txt` 提供 APK 完整性校验。APK 不附带 API Key、发布证书或用户数据，AI 功能需要自行配置服务。

## 验证与边界

- [GitHub CI](https://github.com/damonwl/MutCube/actions/runs/37720330804) 的 Android 单元测试/Lint/Debug 与 Release 构建、SDK 检查及数据库模拟器测试全部通过。
- 发布 APK 使用原发布证书签名，并核验包名、版本、签名和对齐；构建与签名校验不等同于所有真实模型和设备组合的人工验收。
- 本版本仍属预发布：没有账号同步、模板市场或第三方开发者签名认证；Android Skills 不执行附带脚本；健身模板每自然日仅支持一份训练记录。
- 不保证所有模型厂商支持相同的工具、图片和语音协议。AI 建议需自行核对，不替代专业或医疗意见。

## English

The first GitHub prerelease of MutCube: an MIT-licensed Android AI client and template service platform with multi-provider chat, Agent Skills, MCP, voice, project memory, backups, a built-in fitness template, and an English-learning SDK starter.

Download `MutCube-0.1.3-release.apk` for Android 8.0+. Package: `com.dwl.mutcube`; version code: 4. It uses the same release certificate as the previously distributed 0.1.2 APK. Back up your data before upgrading; Debug/Alpha data does not automatically transfer. Configure your own Providers and credentials. Verify the APK with `SHA256SUMS.txt`.

All three GitHub verification jobs passed for the release code. This is a development prerelease, not a guarantee of compatibility with every device or AI service. Account synchronization, a template marketplace, authenticated third-party packages, and Skill script execution are not available.
