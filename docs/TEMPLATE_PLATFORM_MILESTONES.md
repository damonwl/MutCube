# 第三方模板平台：七个工作包与四个里程碑

本轮按“先本地包闭环、后公开市场”实施，不把未落地的宿主 API 写进可安装协议。包格式 `packageVersion=1`，内部 Action 协议仍为 2；详细约束见 [模板包规范](TEMPLATE_PACKAGE_V1.md)。

| 工作包 | 本轮交付 | 验证 |
| --- | --- | --- |
| 1. 协议冻结 | 严格 Manifest、版本、开发者/许可证声明、资源 Hash、权限与域名、集合/Action 协议 | 核心 JVM 协议测试 |
| 2. 宿主能力 | 项目信息、主题、提示/确认、聊天导航、声明式数据 CRUD 与 AI Action；文件/图片选择、剪贴板、受限 HTTPS GET | 宿主 Kotlin 编译、SDK 测试 |
| 3. 本地安装与隔离 | ZIP 校验、大小/数量/路径限制、独立目录、WebView 来源与 CSP、版本升级、卸载保留/清除数据 | 独立 Room 与真实 WebView 的 Android 仪器测试 |
| 4. SDK 与 Mock Host | ES Module、TypeScript 声明、请求关联与超时、Mock Host、权限/主题/Action 调试面板、脱敏调用日志 | Node 测试 |
| 5. 开发者工具 | `init` 默认生成英语学习样板、`validate`、`pack`，并从当前内置协议导出独立训练示例 | 英语/训练示例打包 |
| 6. 用户界面 | 模板管理、本地导入前预览、安装与项目授权、绑定项目提示、卸载时数据选择 | Android 编译与模拟器仪器测试 |
| 7. 数据与验收 | 保留数据默认策略、备份 v3 包含安装资源与 Room 记录、旧备份恢复边界、示例闭环 | 备份/恢复隔离测试、外部页面加载测试 |

里程碑：

1. **M1 可定义**：第三方模板包与能力声明可以被严格解析和拒绝不支持的能力。
2. **M2 可开发**：开发者可在浏览器用 Mock Host 开发，使用 CLI 生成可重复的包。
3. **M3 可安装**：用户可在 App 中预览、授权、运行、升级和卸载本地包，数据由宿主管理。
4. **M4 可验证**：英语学习和训练示例可打包；隔离测试覆盖安装/保留/删除及备份恢复。以下保留早期 Todo 验收记录，当前开发入口不再使用 Todo。
