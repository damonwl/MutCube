# 重建与迁移计划

现有 TOSphone 工作只作为行为参考和验收依据，不作为 MutCube 的源代码基础。

## 里程碑

1. **独立基础**：应用标识、领域模型、构建、测试和持续集成。
2. **聊天纵向闭环**：安全凭据引用、MiMo Provider、流式会话和本地持久化。
3. **空间成员关系**：全局会话可以加入空间，也可以从空间移出。
4. **模板运行时**：Manifest 校验、WebView 隔离、隐藏运行和结构化界面事件。
5. **用户数据治理**：集合契约、授权、不可变历史、计划变更确认和审计日志。
6. **健身验收模板**：资料、当前计划、训练提交、评价、下次计划和日历。
7. **切换到新应用**：可选数据导入、模拟器与真机回归、发布加固。

## 迁移规则

每项能力必须标注为以下一种处理方式：

- `重新实现`：依据 MutCube 需求独立编写；
- `标准依赖`：采用来源明确且许可证兼容的第三方库；
- `格式导入`：只导入用户拥有的数据；
- `延后`：不进入当前里程碑。

未经来源记录和许可证审查，不得把旧项目源文件加入本仓库。
