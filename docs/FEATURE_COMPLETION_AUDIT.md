# 会话与设置能力完成审计

> 本文是 2026-09-15 的阶段性审计，文末“模板不在范围”仅表示当时尚未纳入本轮审计，**不是当前产品状态**。当前模板能力与限制请以 [README](../README.md) 和 [开发进度](PROGRESS.md) 为准。

历史审计日期：2026-09-15；状态说明更新：2026-10-08。

最新修复、重构和验证范围见 [开源准备审查](OPEN_SOURCE_READINESS_AUDIT.md)。
当前文档目录见 [文档导航](README.md)。下方“完成”表示历史阶段结论，不等于本轮重新验收了全部条目。

本文按用户提出的功能清单检查“入口、持久化、运行效果和验证证据”。只有设置项真正影响请求或界面，才记为完成。

## 模型与 Provider

| 要求 | 状态 | 实现边界 |
| --- | --- | --- |
| Provider 启停与排序 | 完成 | 至少保留一个启用档案；活动档案停用时安全回退 |
| 模型收藏、别名、图标 | 完成 | 收藏优先排序；别名与 Emoji/短图标进入列表和回复标识 |
| 模型能力声明 | 完成 | 图片、工具、推理支持三态并约束请求；最大输出长度限制请求参数，上下文窗口供配置与诊断展示 |
| 配置导入、导出、分享 | 完成 | 使用带版本的 JSON；主动排除 API Key |
| 连接诊断与错误 | 完成 | 三种协议分别发现模型；开发者模式显示端点、协议和脱敏原始错误 |
| 供应商范围 | 完成 | 内置常用供应商预设和自定义入口；原生支持 OpenAI-compatible、Google、Anthropic |

## 会话高级能力

| 要求 | 状态 | 实现边界 |
| --- | --- | --- |
| 对话级系统提示词 | 完成 | 对话 > 项目 > 全局优先级 |
| 启动行为 | 完成 | 打开最近会话或进入空白新对话；空白对话不落库 |
| 后续问题建议 | 完成 | 完成回复后独立请求生成，可全局关闭，不写入历史 |
| 快捷提示词 | 完成 | 输入框聚焦后可一键填入，用户确认后发送 |
| Skills、模式、知识条目 | 完成 | Skills 可启停；模式单选；知识按关键词或始终注入，并限制总量 |
| 长文本粘贴 | 完成 | 超过阈值转为应用私有文本附件，避免输入框卡顿 |
| 输入与反馈 | 完成 | 回车发送、振动、停止生成、推理强度滑杆 |
| 后台生成与通知 | 完成 | 用户开启后以前台服务保护生成；完成通知可点击返回，不在锁屏暴露正文 |
| TTS 与 ASR | 完成 | 系统服务和独立 OpenAI-compatible 服务可分别配置，密钥进 Keystore |
| 外观 | 完成 | 主题、字号、背景、气泡、头像、模型标识、时间与自动滚动 |
| 统计与日志 | 完成 | Token、缓存、速度、耗时；开发者模式控制脱敏请求日志 |
| 系统分享与快捷方式 | 完成 | 分享文本/图片/文件进入草稿；对话和项目支持桌面固定快捷方式 |

## 明确不在本轮范围

- 模板运行时及第三方模板安装、签名、沙箱、权限和开发者 SDK；
- 已经与用户约定延后的 Markdown 数学公式、脚注、任务列表增强；
- PDF、旧版 Office、扫描件、音频与视频正文理解；这些文件当前可以选择、保存、展示和分享，但不会伪装成已解析；
- 多设备实时同步。WebDAV/S3 当前是用户主动控制的备份与恢复，不做冲突合并。
