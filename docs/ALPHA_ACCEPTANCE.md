## 凭据与外部服务边界

仪器测试可能重装 Debug 包，因此不会把个人 API Key 纳入自动化测试数据。测试不读取、输出或备份密钥。真实 MiMo 流式请求此前已完成模拟器验收；本次回归以本地协议服务器覆盖请求格式、流式解析和错误映射。

WebDAV、S3、MCP OAuth 等功能需要用户自己的服务端点和账户。本次验收覆盖本地校验、协议实现、失败反馈及相关单元测试，不将不存在的外部账户测试表述为端到端通过。

## 构建产物

`alpha` 构建使用 Android 开发签名并采用独立包名 `com.dwl.mutcube.alpha`，适合本机验收，可与 Debug 版本并存。该签名不是应用商店发布身份；正式发布前应生成并离线保管专用发布密钥。
