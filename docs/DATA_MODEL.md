# 数据模型

## 所有权关系

```text
用户
├── 空间 Space
│   ├── 模板绑定 TemplateBindingEntity
│   └── 会话 Conversation（可选加入）
├── 全局会话 Conversation
├── 全局/项目记忆 MemoryEntry
├── 模板数据 TemplateRecordEntity
└── 数据授权 TemplatePermissionEntity
```

## 核心实体

### 空间 Space

空间是 AI 上下文容器，可以包含指令、模型偏好、记忆策略、模板绑定和数据授权。空间不是聊天，也不被
建模为拟人化的“助手”。
项目可以重命名和置顶。删除项目时，所属会话会原子地移回全局范围，消息历史不受影响。

### 会话 Conversation

用户可见的消息线程。`spaceId` 可以为空；加入或移出空间不会改变会话自身的身份和消息历史。
会话保存创建时间、更新时间和置顶状态。空白新对话只存在于界面状态，发送第一条消息后才创建持久化记录。
创建会话与变更空间归属均由 Repository 校验目标空间；移动归属只更新 `spaceId`，不复制消息，也不改变
会话标识。

删除采用可恢复的软删除：设置 `deletedAt` 后从正常列表隐藏，消息树仍由外键关系完整保留；撤销会清除该
标记。永久清理属于后续数据维护操作，避免误触立即破坏历史。

### 消息节点 MessageNode

会话中的一个逻辑位置是一个消息节点，而不是一行不可替换的文本。节点保存稳定的顺序与当前选中的
`MessageVariant`；重新生成会新增候选版本并切换选择，用户可以在候选版本间切换。`selectedVariantId`
由 Repository 在事务内维护，它必须指向同一节点下的版本。

节点的 `parentVariantId` 指明它由上一个节点的哪个候选版本产生。当前可见消息由根节点开始，沿每个节点
当前选中版本对应的子节点向下遍历。这样编辑旧消息或切换候选回答时，各自的后续上下文不会混合；切回旧
版本仍可恢复原分支。删除节点会递归删除其所有后代路径，派生对话则只复制截至目标节点的当前可见路径。

### 消息版本 MessageVariant

版本保存角色、生成状态、模型、时间、输入/缓存/输出 Token、生成耗时和可选译文。生成状态包括完整 `COMPLETE`、主动中止
`STOPPED` 和失败 `FAILED`。版本身份与节点身份分离，因此后续可以实现分支、编辑与重新生成，而不破坏
会话顺序。
AI 生成版本会保存实际解析后的模型 ID、Provider 返回的 Token 用量和本地测量的生成耗时；重新生成的每个候选版本
各自保留自己的元数据，不覆盖其他候选。
收藏状态属于具体消息版本，而不是整个节点；因此两个候选回答可以分别收藏，派生对话中的副本默认不继承
收藏身份。

### 内容部件 MessageContentPart

一个消息版本由有序内容部件组成。版本 3 数据库已支持文本、附件、推理、工具调用和工具结果；附件进一步
区分图片、文档、音频与视频。数据库使用关系表保存部件，不直接持久化供应商响应对象，也不把所有内容
压成无法检索的 JSON。当前界面仍通过 `ChatMessage` 兼容视图读取选中版本，后续功能逐步迁移到完整结构。

数据库从版本 2 升级时，每条旧消息会无损转换为一个节点、一个选中版本和一个文本部件。
版本 6 迁移会按原顺序为存量节点补齐父版本关系。

### 记忆 MemoryEntry

记忆是用户拥有的稳定事实或偏好，可属于某个项目，也可位于全局。项目内会话检索时只能看到全局记忆和
当前项目记忆；全局会话只能看到全局记忆，其他项目的数据不会越界。AI 写入记忆默认关闭，开启后也只能通过
宿主白名单工具写入，疑似 API Key 或密码的内容会被拒绝。用户可在设置中查看和删除全部记忆。

删除项目时，其记忆会在同一数据库事务中解除项目归属并转为全局记忆，确保所有权不依赖项目生命周期。
数据库版本 10 新增独立的 `memory_entries` 表和作用域、更新时间索引。

### 模板定义与模板绑定

模板定义描述模板包、版本和所需能力。模板绑定将某个版本启用到一个空间。解除绑定或卸载模板不会删除
用户数据。

### 模板数据 TemplateRecordEntity

用户拥有的 JSON 文档，以命名空间、集合和键定位。记录需要保存创建者和变更来源，生命周期独立于模板
是否安装。

### 数据授权 TemplatePermissionEntity

可撤销的项目/模板/集合/操作授权。默认拒绝；启用协议 2 服务时按声明操作计算所需权限。可修改集合支持增删查改，历史集合只追加，版本候选需宿主接受用户确认后生效；受信任内置 GUI 可使用单次可视化启用确认，其他页面默认原生确认，删除仍原生确认。聊天仅调用模板明确开放的查询与生成 Action。

### 模板运行 TemplateRun

可审计的隐藏 AI 执行记录，包含 actionId、输入快照、模型、结果、状态、时间及上下文快照。运行摘要可以参与模板后续
上下文，但不会作为普通聊天展示。

当前数据库为版本 18。17→18 按用户要求一次性清理 8 张旧模板表，不兼容旧协议或业务数据；项目、会话、消息、记忆、Provider 和加密密钥保留。当前通用契约见 TEMPLATE_MODULES.md。
