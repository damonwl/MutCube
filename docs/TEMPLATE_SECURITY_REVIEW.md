# 第三方模板包 v1：安全验收与剩余边界

状态：2026-10-02 发布前复查。此文记录已验证的控制措施，不把本地包误称为受信任的插件或经过独立渗透测试。

## 信任边界

- 模板包是用户主动导入的第三方 Web 代码。开发者名称、网站与许可证均为包作者自述；资源 SHA-256 只防止包内文件与 Manifest 不一致，不能证明作者身份。安装前 UI 明示“来源未验证”。
- 数据属于用户并由宿主 Room 保存。模板只能经已声明 Action 在所绑定项目及获准集合中访问；无法直接读取 Room、API Key、任意文件或其他项目。聊天侧写入限制仍由 Action 渠道执行。
- 页面使用独立虚拟 HTTPS 来源、CSP、关闭 WebView 直接网络/文件/Content 访问。主框架桥接消息必须来自对应来源。`network.fetch` 是单独授权的 HTTPS GET，要求精确域名，拒绝私网 DNS 结果和重定向，限制 128 KiB 与总请求时间。
- 每次宿主桥接调用都会重新核对当前项目绑定与模板版本；解绑或换绑后，已打开的旧页面不能继续调用普通宿主能力。停止语音和关闭页面保留为清理操作。对长时间等待文件、确认或网络的调用，返回前再核对绑定。
- 备份可以保留模板资源及记录，但恢复后数据授权被撤销；重新授权由用户完成。升级不得静默改变已有集合 Schema/策略，卸载默认保留数据。

## 回归覆盖

| 范围 | 覆盖方式 |
| --- | --- |
| ZIP 路径穿越、反斜杠别名重复、Hash 篡改、未声明文件、超大解压文件、截断包 | Android 隔离安装器测试，要求预览和安装都拒绝且临时目录清理 |
| 超长版本号、非法资源路径、错误权限与网络域名 | JVM 协议测试、CLI 独立开发者测试 |
| WebView 直接联网 | 真机隔离页面发起 `fetch`，要求失败或返回禁止状态 |
| URL 伪装、端口/用户信息/子域名、私网与云元数据地址、3xx 跳转 | 网络策略 JVM 测试；HTTP 客户端关闭自动跳转并设总时限 |
| 已打开模板解绑后的宿主能力调用 | 真机语音示例桥接测试，要求返回 `PERMISSION_DENIED` 且服务未被调用 |
| 升级冲突、卸载保留/永久删除、备份恢复 | Android 隔离数据库与真实 WebView 测试，恢复后验证包可识别且旧授权不可使用 |
| Mock Host 敏感内容 | Node 测试确认提示正文不写控制台/调试日志，无模拟服务时不虚报可用；无确认 UI 时默认拒绝 |

以上自动化用例使用隔离数据；没有在用户实际项目写入虚构业务记录。测试不等于所有 WebView、Android 系统版本或网络环境都无漏洞。

## 尚未解决，不能因 v1 冻结而忽略

1. **没有开发者签名、撤销与审核。** 同 ID/开发者名称并非可靠身份验证；用户导入更高版本时仍须检查来源。公开市场之前必须设计签名、密钥轮换和恶意包处置。
2. **模板可使用用户已授权的网络/AI/语音能力。** 若模板被授权读取内容并向允许域名发送，宿主无法替用户判定业务目的是否正当。权限确认需要持续清楚展示域名和敏感能力。
3. **没有通用数据迁移器。** v1 拒绝已有集合 Schema/策略变化；需要迁移的升级不能靠改版本号绕过。
4. **没有独立第三方渗透审计或大规模兼容性矩阵。** 后续公开分发前需安排更多设备、WebView 版本、网络故障与恢复演练。
