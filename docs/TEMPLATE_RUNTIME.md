# 模板运行时

当前实现与边界以 [模块说明](TEMPLATE_MODULES.md) 和 [协议 2](BUILTIN_TEMPLATE_CONTRACT.md) 为准。

## 双入口统一流程

用户在模板 GUI 或项目聊天中操作 → 确定宿主项目实例 → 检查已声明 Action / 入口 / 输入契约 → 检查绑定与集合权限 → 注入宿主上下文 → 校验完整输入 → 执行确定性 CRUD 或 AI 生成 → 校验并事务化保存 → 返回结构化结果。

AI 生成单独保存输入快照和 RUNNING 运行，在失败、超时、取消或进程中断时保留已保存输入，并将运行标记为 FAILED、CANCELLED 或 INTERRUPTED。运行详情保存参数及上下文，不保存凭据和原始敏感请求头。

版本输出是候选，不立即成为当前内容。用户确认后，宿主再次检查授权、源修订及当前修订；通过后只切换指针，不覆盖任何历史版本。宿主可显式允许受信任内置 GUI 将可视化预览后的启用点击作为确认，不再弹出 JSON 窗口；未开启该宿主选项的页面仍使用原生确认。删除仍需原生确认，CHAT 没有版本切换权限。聊天读取的 CURRENT 不包含未确认候选。

运行时只包含通用数据治理、摘要和模型执行逻辑，不包含健身、学习或笔记业务字段分支。
