# MutCube 界面与交互基线 V0.1

本版本用于冻结第一轮主框架交互，Android 实现以 `design/prototype/prototype-v2.html` 为验收参考。

## 主界面

- 顶部左侧打开侧边栏，中间在“聊天 / 模板”之间平级切换。
- 聊天页右上角暂时保留一个功能位；模板页右上角显示模板搜索。
- 新建聊天默认是空白草稿，未发送消息前不进入历史记录，也不显示聊天建议。
- 输入框默认保持紧凑，获得焦点后展开模型强度、相机、语音和附件操作。
- 输入文字后，附件按钮切换为发送按钮。
- 模板页不显示聊天输入框。

## 侧边栏

从上到下依次为：

1. 品牌与搜索；
2. 用户信息及快捷入口；
3. 置顶内容，可同时包含项目和对话；
4. 项目列表；
5. 最近聊天；
6. 固定在底部的新建对话按钮。

“所有聊天”是独立入口，不伪装成项目。项目列表只包含用户创建的项目；点击项目先进入项目详情，而不是直接
筛选全局聊天列表。聊天页右上角的上下文菜单用于将当前会话加入、移动或移出项目。

## 项目与会话导航

- 项目详情页保留项目概览、模板/新建对话快捷入口和最近会话，项目设置统一收纳到右上角菜单。
- 项目详情页的输入框固定在底部，输入并发送后直接在该项目下创建会话。
- 点击项目最近会话直接进入聊天；系统返回或返回手势回到项目详情，便于继续选择同项目的其他会话。
- 从侧边栏或“所有聊天”进入的会话仍遵循全局导航，不强行返回某个项目。
- 生成失败只在对应消息附近显示紧凑感叹号；点击后再显示错误详情和处理入口，避免错误卡片长期占据聊天流。
- 项目设置与对话设置均使用独立全屏页面；系统返回只退出当前设置页，不改变会话或项目来源关系。
- 对话设置明确展示“对话 → 项目 → 全局”的继承关系，避免把未实现的对话级模型覆盖伪装成可编辑项。
- “所有聊天”和“收藏”使用独立页面：前者提供跨项目正文搜索、全部/置顶/最近筛选、回收站和会话操作，后者按具体消息版本跳回原会话并支持取消收藏。
- 设置首页提供实时搜索，按标题和摘要过滤所有功能入口；新建项目使用独立页面一次配置名称、系统提示词及模型继承关系。
- 聊天页右上角是当前对话的统一操作面板，集中提供对话设置、统计、导出、桌面快捷方式和删除，不再把“更多”图标直接等同于设置。

## 附件面板

附件面板从底部弹出，第一阶段提供拍照、相册和本地文件三个入口。实际文件读取、权限申请与上传流程在聊天纵向闭环中实现。

## 组件边界

Android UI 通过 MutCube 自有组件封装实现，页面不得直接依赖第三方库类型：

- `MutCubeTopBar`
- `MutCubeComposer`
- `MutCubeDrawer`
- `TemplateSearch`
- `AttachmentSheet`
- `MessageContent`

基础控件优先使用 AndroidX Compose Material 3；需要高度自定义的底部弹层时，通过适配层使用 Compose Unstyled。
