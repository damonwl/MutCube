# 开发者模式：重置项目模板数据

用于重复测试首次使用、当天记录提交和计划生成，不是日常业务删除能力。

## 操作

1. 设置 → 开发者选项 → 开启“启用开发者模式”，点击保存。
2. 点击“重置项目模板数据”，选择已启用模板的项目。
3. 查看项目、模板及数据/执行记录数量；建议先在数据管理中导出备份。
4. 输入完整项目名称，点击“永久清除”。取消不清除。
5. 重新打开模板，即可从首次使用状态开始。

## 范围与保护

- 清除所选 projectId + templateId 的全部集合数据、当前版本指针、历史版本、摘要缓存、执行记录和审计记录；不受普通分页数量限制。
- 保留模板集合定义、项目、聊天、Provider、API Key、模板绑定与授权；不清除其他项目及已解绑模板的数据。
- 保留聊天意味着 AI 仍可引用原项目会话的内容，重置不是清除项目历史上下文。
- 预览数量是快照，最终清除整个明确范围，包括预览后新增的数据。运行中拒绝重置；项目名称和当前启用绑定在事务内再次校验，失败全部回滚。
- 宿主维护 API 不暴露在 TemplateRuntimeRepository、WebView 桥接或 AI 工具中；入口要求已保存的开发者模式开启。删除不可撤销，只能从用户另行导出的备份恢复。
- 实现无需更改数据库表结构或迁移；不卸载应用，不自动清除真实用户数据。
